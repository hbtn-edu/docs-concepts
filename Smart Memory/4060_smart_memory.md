# Smart Memory: gestión del conocimiento con myReach

## Introducción

Guardar un enlace no garantiza que podamos encontrarlo o recordar por qué era importante. Un sistema de gestión del conocimiento personal busca resolver este problema mediante un proceso continuo:

1. Capturar información útil.
2. Organizarla con un criterio comprensible.
3. Recuperarla mediante búsquedas.
4. Relacionarla con otros conocimientos.
5. Transformarla en conclusiones o productos nuevos.

myReach reúne estas actividades en una base de conocimientos asistida por inteligencia artificial. Permite guardar sitios web, documentos y notas; agruparlos en espacios de trabajo; buscar por palabras clave o significado; y conversar con el contenido mediante un asistente.



## Conceptos principales

### Base de conocimientos

La **Knowledge Base** o base de conocimientos es la colección de información guardada en myReach. No funciona únicamente como una lista de marcadores: cada elemento puede incorporar propiedades, comentarios, relaciones y análisis generados por IA.

### Nodos

Un **nodo** (*Node*) es cualquier elemento individual guardado en myReach, por ejemplo:

- Un sitio web o artículo.
- Un archivo PDF.
- Una nota de texto.
- Un contacto.
- Una etiqueta.

Los nodos son las unidades básicas de la base de conocimientos. Pueden relacionarse entre sí y pertenecer a uno o varios espacios de trabajo.

### Espacios de trabajo

Un **espacio de trabajo** (*Workspace*) agrupa información vinculada con un proyecto, una materia o un área de interés. Por ejemplo:

- Aprendizaje de IA.
- Desarrollo profesional.
- Habilidades técnicas.

myReach incluye dos espacios especiales:

- **Unassigned:** recibe el contenido que todavía no ha sido clasificado.
- **Trash:** contiene los nodos eliminados hasta que se restauran o borran definitivamente.

Si se elimina un espacio de trabajo, los nodos que no pertenezcan a otro espacio se trasladan a **Unassigned**. Eliminar el espacio no elimina automáticamente su contenido.

### Propiedades

Las **propiedades** son metadatos que describen y clasifican los nodos. Existen propiedades predeterminadas y propiedades personalizadas.

Algunas propiedades pueden generarse o completarse automáticamente:

- **AI Status:** indica si la IA pudo procesar el nodo.
- **Description:** resumen breve del contenido.
- **Reading Time:** estimación del tiempo de lectura.
- **Language:** idioma detectado.
- **Author:** autor identificado, cuando esa información está disponible.

También se pueden crear propiedades personalizadas, como prioridad, fecha límite, estado, valoración o tema. Algunas admiten la opción **AI-Populated**, que intenta extraer automáticamente el valor desde el contenido del nodo.

## Crear una cuenta y comenzar

La aplicación web puede abrirse desde [myreach.io](https://myreach.io/). Durante el registro pueden estar disponibles métodos como correo electrónico o cuentas externas.

Una vez dentro, conviene identificar estas secciones:

| Sección | Finalidad |
| --- | --- |
| **Home/Dashboard** | Presenta una vista general y actividad reciente. |
| **Knowledge Base** | Reúne los nodos y permite buscarlos, filtrarlos y organizarlos. |
| **Assistant** | Permite conversar con la información guardada. |
| **Workspaces** | Separa el contenido por proyectos o áreas. |

La interfaz y los nombres exactos pueden cambiar con las actualizaciones del producto. Si una opción no aparece donde se esperaba, se recomienda consultar el manual y el historial de cambios.

## Capturar contenido con la extensión

myReach ofrece una extensión llamada **myReach Web Clipper** para guardar contenido sin abandonar la página que se está consultando.

- [Instalar para Google Chrome](https://chromewebstore.google.com/detail/myreach-web-clipper/kegfimibbdadlkgbiijhljlolgfndcem)
- [Instalar para Mozilla Firefox](https://addons.mozilla.org/en-US/firefox/addon/reach-web-saver/)

Después de instalarla:

1. Abre el menú de extensiones del navegador.
2. Ancla myReach Web Clipper para mantenerlo visible.
3. Inicia sesión con la misma cuenta utilizada en myReach.
4. Visita una página que quieras conservar.
5. Abre la extensión y selecciona **Save Website**.
6. Si la interfaz lo permite, elige uno o varios espacios de trabajo antes de guardar.
7. Comprueba en la base de conocimientos que se haya creado el nodo.

Si no se selecciona un espacio de trabajo, el contenido puede aparecer en **Unassigned** y organizarse posteriormente. La extensión también permite buscar contenido guardado y, en algunos casos, guardar una selección de texto como nota.

### Privacidad y permisos

Para capturar páginas, una extensión necesita acceder al contenido del navegador. Antes de instalarla:

- Revisa los permisos solicitados.
- Confirma que el desarrollador sea myReach.
- Evita guardar información privada, confidencial o institucional sin autorización.
- No captures páginas que contengan credenciales, datos personales sensibles o información protegida.
- Consulta la política de privacidad si no sabes cómo se almacenará o procesará el contenido.

## Diseñar una estructura útil

Una buena organización debe facilitar la recuperación del contenido sin requerir demasiadas decisiones cada vez que se guarda algo.

### Recomendaciones para los espacios de trabajo

- Comienza con categorías amplias y significativas.
- Utiliza nombres claros y mantén una nomenclatura coherente.
- Evita crear espacios diferentes para conceptos casi idénticos.
- Crea un espacio específico para cada proyecto de investigación importante.
- Revisa periódicamente **Unassigned** para clasificar lo pendiente.

### Describir los nodos

Además del resumen generado automáticamente, es útil agregar una nota personal que responda:

- ¿Por qué guardé este contenido?
- ¿Qué problema me ayuda a resolver?
- ¿Cuál es su idea principal?
- ¿Cómo podría utilizarlo más adelante?
- ¿Está de acuerdo o en conflicto con otra fuente?

Estas notas conservan el contexto personal que una descripción automática puede no detectar.

## Construir una biblioteca de calidad

Una base de conocimientos resulta más útil cuando combina formatos y perspectivas diferentes. Puede contener artículos, documentación, tutoriales, PDF, investigaciones, noticias y notas propias.

Antes de guardar un recurso, conviene evaluar:

- **Relevancia:** contribuye a una pregunta o meta concreta.
- **Calidad:** identifica autor, fecha y fuente cuando sea posible.
- **Diversidad:** aporta una perspectiva diferente de las fuentes existentes.
- **Utilidad futura:** contiene información que probablemente será consultada nuevamente.

Guardar muchos enlaces sin revisarlos puede transformar la base de conocimientos en otra bandeja de entrada desordenada. Es preferible conservar menos recursos, pero acompañarlos de una descripción y una clasificación útiles.

## Buscar y recuperar información

### Búsqueda por palabras clave

La búsqueda tradicional intenta encontrar términos concretos en los títulos, propiedades o contenidos. Es adecuada para localizar un autor, una tecnología o una frase conocida.

### Búsqueda semántica

La búsqueda semántica intenta recuperar nodos relacionados con el significado de la consulta, aunque no contengan exactamente las mismas palabras. Puede ser útil para encontrar recursos sobre una idea general o descubrir conexiones entre expresiones diferentes.

Los resultados pueden refinarse con filtros como:

- Tipo de nodo.
- Espacio de trabajo.
- Propiedades.
- Fechas u otros metadatos disponibles.

La relevancia semántica no garantiza que un resultado sea correcto o suficiente. Siempre debe abrirse el nodo y comprobarse la fuente original.

## Procesamiento mediante IA

Cuando se guarda un nodo, myReach comienza a procesarlo. La propiedad **AI Status** puede mostrar estados como:

- **Learned:** el contenido fue procesado y puede utilizarse en respuestas del asistente.
- **Not Learned:** todavía no se encuentra disponible para el asistente.
- **Failed to Learn:** ocurrió un error durante el procesamiento.
- **Unprocessable:** el sistema no puede procesar ese contenido.

El estado **Learned** no significa que la IA haya comprendido el contenido perfectamente; indica que terminó de indexarlo. Conviene comparar la descripción, el idioma, el autor y el tiempo de lectura detectados con la fuente original.

## Utilizar el Asistente de IA

El **Assistant** responde preguntas utilizando los nodos procesados dentro del alcance seleccionado. Su funcionamiento general incluye:

1. **Recuperación:** localiza los nodos considerados relevantes.
2. **Síntesis:** combina la información recuperada para elaborar una respuesta.
3. **Referencias:** muestra las fuentes utilizadas para que puedan verificarse.

La función de razonamiento del chat permite observar partes del proceso, como la búsqueda de fuentes y la elaboración de la respuesta. Esta información ayuda a evaluar el resultado, pero no sustituye la revisión de los nodos citados.

### Cómo formular consultas útiles

Una consulta precisa suele producir resultados mejores que una pregunta demasiado amplia.

```text
Resume las tres ideas principales del artículo sobre [tema] y cita el nodo utilizado.
```

```text
Compara cómo explican [concepto] los nodos [A] y [B]. Señala acuerdos y diferencias.
```

```text
Busca contenido relacionado con [tema] dentro del espacio de trabajo [nombre].
```

```text
¿Qué información falta en mis fuentes para responder [pregunta de investigación]?
```

### Formas de interactuar

| Método | Alcance | Uso recomendado |
| --- | --- | --- |
| **Assistant** | Todos los espacios o los espacios seleccionados. | Consultas amplias y síntesis entre varias fuentes. |
| **Node Filter** | Nodos elegidos manualmente. | Comparar o analizar un conjunto controlado de fuentes. |
| **Chat desde un nodo** | Un nodo y, opcionalmente, sus relaciones directas. | Hacer preguntas específicas sobre un recurso. |
| **Chat Search** | Los resultados de una búsqueda y sus filtros. | Conversar con un subconjunto encontrado mediante búsqueda. |

En el chat desde un nodo, la opción **Node Relationships** controla el alcance:

- Activada: incluye el nodo y sus relaciones directas.
- Desactivada: utiliza solamente el contenido del nodo seleccionado.

## Relaciones y descubrimiento

myReach ofrece varias maneras de conectar información:

### Relaciones

Son conexiones explícitas entre nodos. Pueden representar, por ejemplo, que un artículo explica un concepto, que una nota resume un PDF o que dos fuentes se contradicen.

### Nodos similares

La sección **Similar Nodes** muestra elementos que la IA considera semántica o contextualmente parecidos. El porcentaje de similitud es una señal para explorar, no una medida de veracidad.

### Visualizador 3D

El **3D Visualiser** representa nodos y conexiones como un grafo. Puede utilizarse para:

- Detectar grupos temáticos.
- Explorar conexiones entre proyectos.
- Encontrar nodos aislados.
- Identificar temas muy desarrollados o áreas con poca información.

Las líneas representan relaciones existentes o detectadas. Una visualización llamativa no implica que todas las conexiones sean relevantes: cada relación importante debe revisarse en su contexto.

## Fortalezas y limitaciones de la IA

Al comparar distintos tipos de contenido, es útil evaluar:

- Exactitud de la descripción automática.
- Detección correcta del idioma.
- Identificación del autor.
- Coherencia del tiempo de lectura estimado.
- Capacidad para procesar diferentes formatos.
- Calidad de los nodos similares sugeridos.
- Correspondencia entre la respuesta del asistente y sus fuentes.

Algunas limitaciones habituales son:

- La IA solo puede utilizar correctamente un nodo si fue procesado.
- Un PDF escaneado o una página con contenido restringido puede no extraerse bien.
- Los metadatos pueden faltar o ser incorrectos.
- Los resúmenes pueden omitir matices importantes.
- La semejanza temática no demuestra que dos fuentes estén de acuerdo.
- El asistente puede producir interpretaciones incorrectas incluso cuando cita fuentes reales.

## Flujo recomendado para una investigación

1. Formula una pregunta de investigación concreta.
2. Crea un espacio de trabajo dedicado al proyecto.
3. Guarda fuentes diversas y registra autor, fecha y procedencia.
4. Agrega notas personales sobre la utilidad de cada fuente.
5. Comprueba que los nodos importantes tengan estado **Learned**.
6. Busca por palabras clave y por significado.
7. Utiliza nodos similares y el visualizador para descubrir conexiones.
8. Formula consultas al asistente con un alcance bien definido.
9. Verifica cada afirmación importante en las fuentes originales.
10. Documenta hallazgos, contradicciones, vacíos y decisiones.
11. Redacta la síntesis final con tus propias conclusiones.
